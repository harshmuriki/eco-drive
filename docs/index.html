Stored only in this browser. It's sent only to Google, never to this site or anyone else.

How to get and protect a key
  1. In Google Cloud Console, create a project and an API key.
  2. Enable: Maps JavaScript API, Places API (New), Routes API, Elevation API.
  3. Restrict the key to websites https://harshmuriki.github.io/* (and http://localhost:*/* for testing), and to those four APIs.
  4. Set a budget alert. Personal use usually stays inside Google's free monthly caps.
